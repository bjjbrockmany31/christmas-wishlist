# 🎄 The Nice List — Christmas Wishlist

A free, festive, mobile-friendly Christmas wishlist made with one HTML file. No account, npm, paid hosting, or build system required.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named `christmas-wishlist` at https://github.com/new (choose **Add a README** only if you like; no other settings needed).
2. Open the repository and choose **Add file → Upload files**. Upload `index.html` and `.nojekyll` from this folder, then click **Commit changes**.
3. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and `/ (root)`, then **Save**.
4. GitHub will publish it at `https://YOUR-GITHUB-USERNAME.github.io/christmas-wishlist/`. Confirm this address from the repository's **Settings → Pages** screen.

*Tip:* If GitHub does not display `.nojekyll`, that's okay: this plain HTML site works without it.

## How sharing works

- Add gifts, shopping links, prices, and your name. Your editable list saves in **your current browser** only.
- Use **Share my list** when on your GitHub Pages URL. It generates a **read-only snapshot URL** containing the gifts you've added. Send that link to friends and family. They do not need a GitHub account.
- If you add more gifts afterward, share a **new** link for your updated snapshot. Visiting the plain site address on another device will show that device's own editable list, not yours.
- **Download shareable page** also creates an HTML copy containing your current gifts, suitable to send directly.
- Shared URLs can be long, so for very large wishlists use the HTML download.

Privacy: No accounts, tracking, or database. The website is public, and anyone with a snapshot link can see the gifts and notes in that link. Don't add sensitive personal information.
